# GRC Analytics — Apresentação

Apresentação comercial em três páginas, com automações com IA, integração de sistemas e dashboards em Power BI.

## Arquivo

`index.html` reúne HTML, CSS, JavaScript e a logo PNG incorporada. Funciona sem dependências externas.

## Navegação

- Botões de navegação e páginas no cabeçalho.
- Setas esquerda/direita e teclas Page Up/Page Down.
- Deslize horizontal no celular.
- Respeita a preferência de movimento reduzido.

## Publicação

Repositório separado do site institucional `grc-analytics-site`.
GitHub Pages: publicar a raiz da branch `main`.

## Conteúdo

Serviços baseados no portfólio fornecido pela GRC Analytics e escopos dos dashboards existentes. O painel ilustrativo usa dados fictícios identificados na apresentação.
